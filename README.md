## Français

Chères futures docteures, chers futurs docteurs,

Merci d'utiliser cet outil pour faire publier l'annonce de ta soutenance sur le site du laboratoire Navier. Voici quelques consignes :

1. **Ouvrir l'outil dans ton navigateur.** Télécharge le fichier `annonce-soutenance.html` (bouton « Download raw file » sur GitHub), puis ouvre-le en double-cliquant dessus. Attention : cliquer simplement sur le fichier dans GitHub affiche le code source, pas le formulaire.
2. **Remplir avec exactitude** les informations de ta soutenance (nom, équipe, date, heure, lieu, jury avec affiliations et rôles).
3. **Titre et résumé** : en français, ou à défaut en anglais.
4. **Lieu de soutenance** : écris quelque chose qui complète bien le mot « dans », par exemple « l'amphithéâtre Cauchy, École nationale des ponts et chaussées » ou « la salle B105, bâtiment Bienvenüe ».
5. **Visioconférence** : si un lien visio est prévu, crée-le avant de remplir le formulaire, puis colle-le dans le champ dédié. Il apparaîtra dans l'annonce sous la forme d'un lien cliquable « ce lien ».
6. **Vérifier le texte** qui s'affiche à droite : c'est exactement ce qui sera publié.
7. **Envoyer** : coche la case de confirmation, puis clique sur « Envoyer par email ». Le code HTML de l'annonce est copié automatiquement et ton application mail s'ouvre avec un message pré-rempli. Colle le code (Ctrl+V / Cmd+V) à l'endroit indiqué `>>> COLLER ICI LE CODE HTML <<<`, puis envoie le mail.

**Si ton application mail ne s'ouvre pas** : clique sur « Copier le code HTML » (en bas, section « Afficher le code HTML pour le site »), puis envoie-le par mail à ana.loyola@enpc.fr avec pour objet « Publication d'annonce de soutenance de thèse – Ton nom ».

Allez, bon courage pour ta soutenance !

## English

Dear future doctors,

Thank you for using this tool to have your thesis defense announced on the Navier laboratory website. Please follow these instructions:

1. **Open the tool in your browser.** Download the file `annonce-soutenance.html` (“Download raw file” button on GitHub), then double-click it to open it. Note: simply clicking the file on GitHub shows the source code, not the form.
2. **Fill in the details of your defense accurately** (name, team, date, time, location, jury members with their affiliations and roles).
3. **Title and abstract**: in French or in English.
4. **Defense location**: the announcement is written in French and places the word “dans” (“in”) before the location, so write something that reads naturally after it, e.g. « l'amphithéâtre Cauchy, École nationale des ponts et chaussées » or « la salle B105, bâtiment Bienvenüe ».
5. **Video conference**: if a video link is planned, create it before filling in the form, then paste it in the dedicated field. It will appear in the announcement as a clickable link (« ce lien »).
6. **Check the text** displayed on the right: it is exactly what will be published.
7. **Send**: tick the confirmation box, then click “Envoyer par email”. The HTML code of the announcement is copied automatically and your mail application opens with a pre-filled message. Paste the code (Ctrl+V / Cmd+V) where indicated `>>> COLLER ICI LE CODE HTML <<<`, then send the email.

**If your mail application does not open**: click “Copier le code HTML” (at the bottom, under “Afficher le code HTML pour le site”), then email it to ana.loyola@enpc.fr with the subject “Publication d'annonce de soutenance de thèse – Your name”.

Good luck with your defense!
