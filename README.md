## Français

Chères futures docteures, chers futurs docteurs,

Merci d'utiliser cet outil pour faire publier l'annonce de ta soutenance sur le site du laboratoire Navier. Voici quelques consignes :

1. **Ouvrir l'outil dans ton navigateur.** Télécharge le fichier `annonce-soutenance.html` (bouton « Download raw file » sur GitHub), puis ouvre-le en double-cliquant dessus. Attention : cliquer simplement sur le fichier dans GitHub affiche le code source, pas le formulaire.
2. **Remplir avec exactitude** les informations de ta soutenance (nom, équipe, date, heure, lieu, jury avec affiliations et rôles). Tu peux aussi, de façon optionnelle, indiquer la langue de la soutenance (français ou anglais).
3. **Titre et résumé** : en français et en anglais, sauf si la version anglaise n'est pas disponible. Dans ce cas, la version française sera reprise sur la page anglaise du site.
4. **Lieu de soutenance** : choisis le type de lieu (amphithéâtre, salle ou auditorium), puis indique uniquement le nom du lieu (ex. « Navier », « B102 ») et le bâtiment ou l'établissement (ex. « École Nationale des Ponts et Chaussées »). **N'utilise ni abréviations ni sigles** (pas de « Amphi », « ENPC », etc).
5. **Visioconférence** : si un lien visio est prévu, crée-le avant de remplir le formulaire, puis colle-le dans le champ dédié. Il apparaîtra dans l'annonce sous la forme d'un lien cliquable « ce lien ».
6. **Vérifier le texte** qui s'affiche à droite, en français **et** en anglais (boutons « Aperçu FR » / « Preview EN ») : c'est exactement ce qui sera publié.
7. **Envoyer** : coche la case de confirmation, puis clique sur « Envoyer par email ». Les codes HTML de l'annonce (français et anglais) sont copiés automatiquement et ton application mail s'ouvre avec un message pré-rempli. Colle les codes (Ctrl+V / Cmd+V) à l'endroit indiqué `>>> COLLER ICI LES CODES HTML <<<`, puis envoie le mail.

**Si ton application mail ne s'ouvre pas** : ouvre la section « Afficher les codes HTML pour le site » en bas, copie les codes FR et EN, puis envoie-les par mail à ana.loyola@enpc.fr avec pour objet « Publication d'annonce de soutenance de thèse – Ton nom ».

Allez, bon courage pour ta soutenance !

## English

Dear future doctors,

Thank you for using this tool to have your thesis defense announced on the Navier laboratory website. Please follow these instructions:

1. **Open the tool in your browser.** Download the file `annonce-soutenance.html` (“Download raw file” button on GitHub), then double-click it to open it. Note: simply clicking the file on GitHub shows the source code, not the form.
2. **Fill in the details of your defense accurately** (name, team, date, time, location, jury members with their affiliations and roles). You may also, optionally, indicate the language of the defense (French or English).
3. **Title and abstract**: in French and in English, unless the English version is not available. In that case, the French version will be used on the English page of the website.
4. **Defense location**: select the type of place (amphitheatre, room or auditorium), then enter only the name of the place (e.g. “Navier”, “B102”) and the building or institution (e.g. “École Nationale des Ponts et Chaussées”). **Do not use abbreviations or acronyms** (no “Amphi”, “ENPC”, etc).
5. **Video conference**: if a video link is planned, create it before filling in the form, then paste it in the dedicated field. It will appear in the announcement as a clickable link (« ce lien »).
6. **Check the text** displayed on the right, in French **and** English (“Aperçu FR” / “Preview EN” buttons): it is exactly what will be published.
7. **Send**: tick the confirmation box, then click “Envoyer par email”. The HTML codes of the announcement (French and English) are copied automatically and your mail application opens with a pre-filled message. Paste the codes (Ctrl+V / Cmd+V) where indicated `>>> COLLER ICI LES CODES HTML <<<`, then send the email.

**If your mail application does not open**: open the “Afficher les codes HTML pour le site” section at the bottom, copy the FR and EN codes, then email them to ana.loyola@enpc.fr with the subject “Publication d'annonce de soutenance de thèse – Your name”.

Good luck with your defense!
